# Smart Hospital Patient Flow & Resource Management System

A real-time multi-hospital patient-flow and resource-management platform.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Python, Django, Django REST Framework
- Database: AvienCloud
- ML: Python, Scikit-learn
- Real-time: WebSockets / Django Channels
- API Testing: Postman

## Core Modules 

- Patient Management
- Hospital Management
- Appointment Management
- OPD Queue Management
- Emergency Management
- Bed Management
- Bed Queue
- Doctor Management
- Admission Management
- Hospital Search
- Transfer Management
- Waiting-Time Prediction
- Notifications
- Analytics
